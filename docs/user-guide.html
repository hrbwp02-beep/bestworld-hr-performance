1. การเข้าสู่ระบบ

เปิดเว็บไซต์ของระบบผ่านเบราว์เซอร์ (รองรับทั้งคอมพิวเตอร์และมือถือ)

  1. เปิด https://hrbwp02-beep.github.io/bestworld-hr-performance/
  2. กรอก อีเมล และ รหัสผ่าน ที่ได้รับ แล้วกด เข้าสู่ระบบ
  3. หากลืมรหัสผ่าน กด “ลืมรหัสผ่าน?” ระบบจะส่งลิงก์รีเซ็ตไปยังอีเมล
บัญชีผู้ดูแลระบบ (HR) เป็นผู้สร้างบัญชีให้ผู้ใช้คนอื่น (ดูหัวข้อ 9) · เปิดครั้งแรกอาจใช้เวลาโหลด 2–3 วินาที

2. ภาพรวมการใช้งาน & เมนูหลัก

เมนูอยู่แถบด้านซ้าย แตะไอคอนเมนู (☰) เพื่อย่อ/เปิดบนมือถือ

เมนูใช้ทำอะไร
ภาพรวมสรุปผลทั้งองค์กร: จำนวนพนักงาน, ความคืบหน้าการประเมิน, คะแนนเฉลี่ย, กราฟแนวโน้ม
มุมมองผู้บริหารเจาะลึก KPI บริษัท → หน่วยงาน → ทีม → รายบุคคล
พนักงานทะเบียนพนักงาน เพิ่ม/แก้ไข/นำเข้า/ดูโปรไฟล์
KPI หน่วยงานกำหนดตัวชี้วัด, ส่งรายงาน KPI, คำนวณคะแนน, ไฟจราจร
ฟอร์มประเมินประเมิน KPI + Competency + ตาม JD พร้อมสายอนุมัติ
จัดการ JDคลัง Job Description แยกตามตำแหน่ง
รายงาน9-Box, Heatmap, จัดอันดับ, เปรียบเทียบย้อนหลัง, Export
Calibrationปรับเทียบคะแนน, Talent Matrix, ผู้สืบทอด
ตั้งค่ารอบประเมิน, น้ำหนักคะแนน, สมรรถนะ, สิทธิ์ผู้ใช้, หน่วยงาน

ด้านบนขวามีปุ่ม แจ้งเตือน 🔔 และเมนูโปรไฟล์ (ออกจากระบบ)

3. หน้าภาพรวม (Dashboard)

  • การ์ดสรุป: พนักงานทั้งหมด, ประเมินแล้ว (%), รอดำเนินการ, คะแนนเฉลี่ยองค์กร, หน่วยงานอันดับ 1
  • กราฟ: แนวโน้มคะแนนรายเดือน, KPI ตามหน่วยงาน, การกระจาย Competency, สถานะการประเมิน
  • ปุ่ม รีเฟรช ดึงข้อมูลล่าสุดจากฐานข้อมูล · ปุ่ม ส่งออกรายงาน ดาวน์โหลดไฟล์ CSV
  • เลือกปีรอบประเมินได้ที่มุมขวาบน (ปี 2569 / 2568)
ตัวเลขทั้งหมดคำนวณจากข้อมูลจริงในระบบ และอัปเดตอัตโนมัติเมื่อมีการเพิ่มพนักงานหรือบันทึกผลประเมิน

4. จัดการพนักงาน

เพิ่มพนักงานทีละคน

  1. เมนู พนักงาน → ปุ่ม เพิ่มพนักงาน
  2. อัปโหลดรูป (กด “อัปโหลดรูป”), กรอกชื่อ, หน่วยงาน, ตำแหน่ง
  3. ระดับ จะถูกแนะนำจากตำแหน่งอัตโนมัติ (แก้เองได้)
  4. เลือก วันเข้างาน — ระบบคำนวณ “อายุงาน” ให้อัตโนมัติ
  5. กด บันทึก

นำเข้าพนักงานจาก Excel (จำนวนมาก)

  1. กด นำเข้า Excel → กด “ดาวน์โหลดเทมเพลต” เพื่อดูคอลัมน์ที่ต้องใช้
  2. คอลัมน์: รหัสพนักงาน (ถ้ามี จะใช้เป็นรหัสจริง), ชื่อ-นามสกุล, หน่วยงาน, ตำแหน่ง, ระดับ, วันเข้างาน, อีเมล, เบอร์โทร, KPI, Competency
  3. วันเข้างานรองรับทั้ง วว/ดด/ปปปป, ปี พ.ศ./ค.ศ. และวันที่ของ Excel
  4. เลือกไฟล์ → ดูตัวอย่าง (ระบบจะเตือนแถวที่ข้อมูลไม่ครบ) → กด “นำเข้า”
  5. ติ๊ก “อัปเดตถ้ามีชื่อ/รหัสซ้ำ” เพื่อนำเข้าไฟล์เดิมซ้ำได้โดยไม่สร้างข้อมูลซ้ำ

โปรไฟล์พนักงาน

คลิกชื่อพนักงานเพื่อดูโปรไฟล์: รูป, ข้อมูลพื้นฐาน, อายุงาน, คะแนนรวม, เรดาร์สมรรถนะ, ประวัติการประเมิน · มีปุ่ม Export, แก้ไข, ลบ, ประเมินผล

ถ้ายังไม่ได้ประเมิน โปรไฟล์จะแสดง “ยังไม่ได้ประเมินรอบนี้” แทนคะแนน 0

5. ประเมินผลพนักงาน

เข้าได้จากโปรไฟล์พนักงาน → ปุ่ม “ประเมินผล” แบ่งเป็น 3 ส่วน + ขั้นอนุมัติ

  1. A · KPI — กรอกผลจริงเทียบเป้าหมาย คะแนนคำนวณอัตโนมัติ (น้ำหนัก 50%)
  2. B · Competency — ให้ดาว 5 สมรรถนะ พร้อมความเห็น (น้ำหนัก 25%)
  3. C · ตาม JD — ให้คะแนนหัวข้อหน้าที่ตาม Job Description (น้ำหนัก 25%)
  4. สรุป & อนุมัติ — ตรวจคะแนนรวม, ใส่ความเห็น แล้วกด อนุมัติผลการประเมิน
เมื่ออนุมัติ ระบบจะบันทึกคะแนนเข้าฐานข้อมูล อัปเดตโปรไฟล์ (วงแหวนคะแนน/เรดาร์/ประวัติ) และตัวเลขบน Dashboard ทันที · กด “บันทึกร่าง” เพื่อบันทึกไว้ก่อนได้

6. KPI หน่วยงาน

แท็บการใช้งาน
ภาพรวมไฟจราจรทุกหน่วยงาน (เขียว/เหลือง/แดง), Achievement, Heatmap, สถานะการส่งรายงาน, รายการล่าช้า
กำหนด KPIเพิ่ม/แก้ไขตัวชี้วัดแยกตามหน่วยงาน (น้ำหนัก/เป้า/ผลจริง/วิธีคิด) · อนุมัติ/ปฏิเสธ KPI ที่ผู้จัดการเสนอ
ส่งรายงานกด ส่งรายงาน เลือกหน่วยงาน/งวด + แนบไฟล์ (Excel/PDF/รูป) → คลิกรายการเพื่อดู/อนุมัติ/ตีกลับ/แนบไฟล์เพิ่ม
คำนวณคะแนนเครื่องคิดเลข 4 สูตร (ยิ่งสูงดี/ยิ่งต่ำดี/อยู่ในช่วง/กำหนดเอง)
เมื่อส่ง/อนุมัติรายงานในแท็บ “ส่งรายงาน” ตัวเลข “รายงานส่งแล้ว X/7” และรายการติดตามในแท็บ “ภาพรวม” จะอัปเดตเองตามรอบปีปัจจุบัน

7. จัดการ Job Description (JD)

  • เมนู จัดการ JD → ปุ่ม สร้าง JD (ระบุตำแหน่ง, หน่วยงาน, จำนวน KPI/Competency, หน้าที่ความรับผิดชอบ)
  • คลิกการ์ด JD เพื่อดูรายละเอียด · กด “แก้ไข JD” เพื่อปรับปรุง
  • กรองตามหน่วยงานได้จากแถบชิปด้านบน

8. รายงาน & Calibration

  • รายงาน: 9-Box Matrix, Heatmap, จัดอันดับพนักงาน, High Potential / กลุ่มเสี่ยง, เปรียบเทียบย้อนหลังรายปี · ปุ่ม “Export Excel” (CSV) และ “PDF” (สั่งพิมพ์)
  • Calibration: เปรียบเทียบคะแนนระหว่างหน่วยงาน, Talent Matrix, ผู้สืบทอดตำแหน่ง

9. ตั้งค่าระบบ & สิทธิ์ผู้ใช้งาน

เมนู ตั้งค่า (เฉพาะผู้ดูแลระบบ)

รอบการประเมิน & น้ำหนักคะแนน

กำหนดชื่อรอบ (ใส่ปี เช่น “รอบประเมินผลประจำปี 2569”), วันเริ่ม–ครบกำหนด, เปิด/ปิดให้ประเมิน และน้ำหนัก KPI/Competency/JD (รวม 100%) → กด บันทึกการตั้งค่า

เปลี่ยนปีในชื่อรอบ แล้วทั้งระบบ (หัวข้อ, ตัวกรองปี, รายงาน) จะอ้างอิงปีนั้นโดยอัตโนมัติ

สิทธิ์ผู้ใช้งาน (สร้างบัญชีล็อกอินจริง)

  1. กด เพิ่มผู้ใช้ → กรอกชื่อ, อีเมล, รหัสผ่านเริ่มต้น (มีปุ่มสุ่ม), เลือกบทบาท
  2. ผู้ใช้จะ ล็อกอินได้ทันที ด้วยอีเมล + รหัสนั้น
  3. สลับสวิตช์เพื่อเปิด/ปิดการเข้าถึง · ไอคอนดินสอ=แก้ไข · กากบาท=ลบ (ลบบัญชีล็อกอินด้วย)
บทบาทสิทธิ์โดยย่อ
ผู้ดูแลระบบเข้าถึงทุกฟังก์ชัน + จัดการผู้ใช้/ตั้งค่า
ฝ่ายบุคคล (HR)จัดการพนักงาน/หน่วยงาน, รอบประเมิน, อนุมัติผล
ผู้จัดการฝ่ายดู/ประเมิน/อนุมัติทีม, เสนอ KPI หน่วยงาน
หัวหน้างานประเมินผู้ใต้บังคับบัญชา
พนักงานทั่วไปดูผล + ประเมินตนเอง

สมรรถนะ & หน่วยงาน

เพิ่ม/แก้ไข/ลบหัวข้อสมรรถนะ (Competency) และเพิ่ม/แก้ไขหน่วยงาน (รหัส, ชื่อ, สี, จำนวนคน) ได้ในหน้าตั้งค่า

10. คำถามที่พบบ่อย

คำถามคำตอบ
เพิ่มพนักงานแล้วทำไม Dashboard “ประเมินแล้ว” ยังเป็น 0?เพราะยังไม่ได้ประเมิน เมื่อประเมินผ่านปุ่ม “ประเมินผล” ตัวเลขจะขึ้นเอง
นำเข้า Excel แล้วบางคนอายุงานไม่ขึ้น?เพราะช่องวันเข้างานว่างหรือรูปแบบวันที่ไม่ถูกต้อง แก้วันเข้างานในไฟล์แล้วนำเข้าซ้ำ (ติ๊กอัปเดตถ้าซ้ำ)
แก้ข้อมูลแล้วเห็นของเก่า?กด “รีเฟรช” หรือรีเฟรชหน้าเว็บ (Ctrl+F5)
เพิ่มผู้ใช้แล้วล็อกอินไม่ได้?ตรวจอีเมล/รหัสผ่านที่ตั้งไว้ หรือให้ผู้ดูแลตั้งรหัสใหม่
ข้อมูลปลอดภัยไหม?ทุกตารางเปิด Row Level Security เฉพาะผู้ล็อกอินเข้าถึงได้ · ไฟล์/รูปเก็บบน Supabase Storage
